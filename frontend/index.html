Privacy and Analysis

How this feature will work

✓ Camera starts only after your action and permission.
✓ Camera can be stopped at any time.
✓ Camera stays active while you move between NeuroSense pages. Use Stop Camera when finished.
✓ Face landmarks are processed locally in this browser.
Analysis status: Face landmarks only
MediaPipe Face Landmarker detects facial landmarks and draws a face-mesh overlay locally in this browser. Webcam frames are not uploaded to NeuroSense or stored by this feature. The MediaPipe library and model load from Google's CDN, and its service may collect usage metrics. This feature detects landmarks only; it is not currently an input to the wearable stress model and does not infer emotion or stress.
